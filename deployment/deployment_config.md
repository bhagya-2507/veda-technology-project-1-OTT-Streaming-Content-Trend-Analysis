
# Deployment and Execution Configuration

## Project
OTT Streaming Content Trend Analysis

## Environment
- Python 3.x
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite

## Setup Instructions
1. Open the project folder in VS Code.
2. Ensure `netflix_titles.csv` is inside the `data/` folder.
3. Install dependencies using `pip install -r requirements.txt`.
4. Open `notebooks/OTT_Content_Trend_Analysis.ipynb`.
5. Run all notebook cells from top to bottom.

## Database
SQLite is used for local SQL analysis. The database is created by the notebook.

## Outputs
- Charts: `outputs/`
- SQL queries: `sql/ott_analysis.sql`
- Reports: `report/`

## Deployment Type
This is a local data analytics project, not a deployed web application.
